# 🎮 Rock Paper Scissors: Probability Simulator

A high-performance Python simulation that pits two bots against each other to analyze the statistical probabilities of Rock, Paper, Scissors over thousands (or millions) of games.

## ✨ Features
*   **Massive Simulations:** Run as many iterations as your CPU can handle.
*   **Flexible Input:** Supports formatted numbers (e.g., `1,000,000`) for better readability.
*   **OOP Architecture:** Uses Python classes to calculate and manage game statistics.
*   **Probability Analysis:** Instant breakdown of Win/Loss/Draw percentages.

## 🚀 How to Run
1. **Clone the repository:**
   ```bash
   git clone https://github.com/rrbhanderi05/rock_p_s-monte_carlo-simulation.git
   ```
2. **Enter the directory:**
   ```bash
   cd rock-paper-scissors
   ```
3. **Run the simulator:**
   ```bash
   python main.py
   ```

## 🛠️ Built With
*   **Python 3**
*   `random` module for stochastic modeling.
*   `while` loops & `if-else` logic for game rules.
*   **Object-Oriented Programming (OOP)** for result processing.

## 📊 Example Output
```text
Enter The Number (Times) You Want Let The Bots Play: 10,000

The following data is based on 10,000 plays:
The Probability Of Winning Is : 33.42%
```

## 🛑 Note on Accuracy
The sum of the results may occasionally show slight floating-point variances (binary issues) common in hardware calculations when dealing with high-precision percentages.
